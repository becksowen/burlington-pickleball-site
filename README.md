# Burlington Early Birds Pickleball Singles

A single-page website built for **Burlington Early Birds Pickleball Singles**, a local community group for singles pickleball players in Burlington, Ontario.

🔗 **Live site:** [www.pickleballsingles.ca](https://www.pickleballsingles.ca) (also available at [www.singlespickleball.ca](https://www.singlespickleball.ca))

## About

The site gives the group a simple, public home base — information about the group and a way for interested players to get in touch and join.

## Features

- Clean, single-page layout introducing the group
- Enquiry form for prospective members, wired directly to email
- Lightweight and fast — no backend required

## Tech Stack

- **HTML** — page structure and content
- **Formspree** — handles enquiry form submissions and routes them to email
- **Netlify** — hosting and deployment (deployed via Netlify Drop)

## Notes

During development, a duplicate element ID bug was identified and fixed — it had been silently breaking the enquiry form's validation.
